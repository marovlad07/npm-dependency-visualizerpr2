# Граф зависимостей npm

Практическая работа №2 по конфигурационному управлению.
Группа ИКБО-71-25, вариант 14. Язык реализации: Python 3.10+.

## Быстрый запуск на этом компьютере

1. Для офлайн-примера дважды нажмите `demo.bat`.
2. Для трех настоящих npm-пакетов запустите `demo_all.bat` (нужен Интернет).
3. Для проверки всех тестов запустите `test.bat` из PowerShell.
4. Инструкция по защите: [docs/DEFENSE.md](docs/DEFENSE.md).
5. Результаты сравнения: [docs/COMPARISON.md](docs/COMPARISON.md).

На этом компьютере `run.bat` и `test.bat` уже настроены на имеющийся
Python, а Graphviz находится в локальной `.tools`. Эта папка не
публикуется в Git и не входит в исходники.

## Установка после клонирования на другой компьютер

- Установите Python 3.10 или новее, с командой `py` или `python`.
- Для изображений установите [Graphviz](https://graphviz.org/download/).
  Добавьте папку с `dot.exe` в PATH либо передайте ее через `--dot`.
- Python-зависимостей нет, `pip install` не требуется. Сборка не нужна.
- Команды ниже запускайте из корня проекта.

Для Linux/macOS эквивалент `run.bat`:

```sh
PYTHONPATH=src python3 -m npm_graph --package is-odd --version 3.0.1
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## Опции командной строки

| Опция | Значение |
|---|---|
| `--package` | Обязательное имя npm-пакета, включая `@scope/name` |
| `--version` | Обязательная полная версия корневого пакета: `3.0.1` |
| `--repository` | URL npm-реестра, по умолчанию `https://registry.npmjs.org` |
| `--test` | Читать JSON по пути из `--repository`, имена пакетов A-Z |
| `--mode config` | Вывести настройки, без запросов к сети |
| `--mode direct` | Показать прямые зависимости указанной версии |
| `--mode graph` | Вывести полный достижимый граф в JSON (по умолчанию) |
| `--mode reverse` | Показать прямые и транзитивные обратные зависимости |
| `--target` | Узел `имя@версия` для reverse; по умолчанию корень |
| `--mode dot` | Вывести описание Graphviz DOT в стандартный вывод |
| `--mode visualize` | Сохранить и открыть изображение |
| `--output` | Путь PNG/SVG; по умолчанию `generated/dependencies.png` |
| `--dot` | Путь к исполняемой программе Graphviz |
| `--no-open` | Сохранить изображение без открытия окна |
| `--help` | Показать справку |

Код успешного завершения — 0, ошибки параметров/данных/сети/рендера — 2.
Неподдерживаемые зависимости не пропускаются: программа сообщает ошибку.

## Этап 1

Минимальное CLI-приложение принимает имя пакета, версию, URL реестра
либо путь к тестовому репозиторию и флаг тестового режима.
Опция `--mode config` выводит параметры в формате ключ-значение.
Ошибочные параметры завершают программу с кодом 2.

```powershell
.\run.bat --package is-odd --version 3.0.1 --mode config
.\test.bat
```

Внешние Python-библиотеки и сборка не нужны. Исходники находятся в `src`,
тесты в `tests`. На другом компьютере установите Python 3.10+.

## Этап 2

Получение метаданных выполняется прямым HTTP-запросом через `urllib`.
Версия корневого пакета задается полностью: например `3.0.1`.
Данные берутся из `versions[version].dependencies`, а не из `latest`.
Встроенный SemVer-резолвер поддерживает точные версии, теги, `^`, `~`,
сравнения, частичные версии, `x`, `*`, дефисные диапазоны и `||`.

```powershell
.\run.bat --package is-odd --version 3.0.1 --mode direct
```

## Этап 3

Граф строится BFS с очередью `deque`, без рекурсии. Узел идентифицируется
парой `(имя, версия)`. Множество обнаруженных узлов предотвращает
бесконечный обход циклов; все ребра, включая обратные, сохраняются.
Для каждого диапазона выбирается максимальная подходящая версия.
Сетевые ответы кешируются в памяти. Лимит 5000 узлов вызывает ошибку,
а не выдает незаметно обрезанный граф.

```powershell
.\run.bat --test --repository examples/cycle.json --package A --version 1.0.0
.\run.bat --test --repository examples/diamond.json --package A --version 1.0.0
.\run.bat --package is-odd --version 3.0.1 --mode graph
```

Вывод `graph` имеет формат JSON. Примеры `chain`, `diamond`, `cycle`,
`empty`, `self`, `versions` показывают цепочку, общую зависимость,
цикл, отсутствие зависимостей, петлю и разные версии одного пакета.
Недостижимый Z из `diamond.json` не входит в граф корневого A.

## Этап 4

Обратные зависимости вычисляются тем же BFS на графе с перевернутыми
ребрами. Показываются прямые и все транзитивные зависимые пакеты.
Сам целевой пакет исключается из результата даже при цикле или петле.
В тестовом режиме анализируется весь файл репозитория, включая пакеты,
недостижимые из указанного корня. Для реального npm анализ ограничен
графом выбранного корня: npm API не дает полный список глобальных
обратных зависимостей. Поэтому корнем следует выбирать верхний пакет,
а `--target` указывает интересующий узел внутри его графа.

```powershell
.\run.bat --test --repository examples/diamond.json --package D --version 1.0.0 --mode reverse
.\run.bat --test --repository examples/cycle.json --package A --version 1.0.0 --mode reverse
.\run.bat --test --repository examples/empty.json --package A --version 1.0.0 --mode reverse
.\run.bat --package is-odd --version 3.0.1 --mode reverse --target is-number@6.0.0
```

## Этап 5

Программа сама формирует DOT и передает его внешней программе `dot`.
Graphviz не получает зависимости и не строит логическую модель пакетов:
он только размещает уже подготовленные узлы и стрелки на изображении.
Изображение открывается в системном приложении по умолчанию.

```powershell
.\run.bat --package chalk --version 4.1.2 --mode visualize
.\run.bat --package chalk --version 4.1.2 --mode dot
.\demo_all.bat
```

Три проверенных примера: `is-odd@3.0.1`, `is-even@1.0.0`, `chalk@4.1.2`.
Узлы и связи всех трех графов совпали со штатной визуализацией `npm ls`.
Полная методика, ограничения и фактические результаты сохранены в
[docs/COMPARISON.md](docs/COMPARISON.md).

## Формат тестового репозитория

```json
{
  "packages": {
    "A": {"1.0.0": {"dependencies": {"B": "^1.0.0"}}},
    "B": {"1.0.0": {"dependencies": {}}}
  }
}
```

Каждая версия имеет отдельный манифест. `dependencies` можно опустить
для листового узла. Ссылка на отсутствующий пакет или неподходящий
диапазон вызывает ошибку. Готовые случаи находятся в `examples/`.

## Устройство проекта и функции

| Модуль | Назначение |
|---|---|
| `cli.py` | Разбор настроек, проверка ошибок, выбор режима и вывод |
| `registry.py` | Узел Package, HTTP-запросы, кеш и чтение dependencies |
| `semver.py` | Разбор/сравнение версий и разрешение диапазонов |
| `test_repository.py` | Загрузка, проверка и чтение тестового JSON |
| `graph.py` | BFS, построение графа, обратные зависимости, JSON |
| `visualization.py` | Формирование DOT, поиск Graphviz, рендер и просмотр |

Справочник всех функций: [docs/API.md](docs/API.md).
Для обхода графа время O(V+E), память O(V+E) без учета стоимости
HTTP-запросов, разрешения версий и сортировки для стабильного вывода.
Итеративный обход проверен на цепочке длиной 1501 узел.

результаты сравнения npm сохранены отдельно в `docs/results`.

Каждый этап сохранен своим коммитом с сообщением `feat(область): ...`.

`File → Add local repository`, выберите эту папку и нажмите
`Publish repository`. Для публичного доступа снимите
`Keep this code private`. После публикации проверьте README и историю
коммитов в браузере. На семинаре нужны запуск программы и защита этапов.
