# Граф зависимостей npm

Практическая работа №2 по конфигурационному управлению.
Группа ИКБО-71-25, вариант 14. Язык реализации: Python 3.10+.

## Этап 1

Минимальное CLI-приложение принимает имя пакета, версию, URL реестра
либо путь к тестовому репозиторию и флаг тестового режима.
Опция `--mode config` выводит параметры в формате ключ-значение.
Ошибочные параметры завершают программу с кодом 2.

```powershell
.\run.bat --package is-odd --version 3.0.1 --mode config
.\test.bat
```

Внешние Python-библиотеки и сборка не нужны. Исходники находятся в `src`,
тесты в `tests`. На другом компьютере установите Python 3.10+.

## Этап 2

Получение метаданных выполняется прямым HTTP-запросом через `urllib`.
Версия корневого пакета задается полностью: например `3.0.1`.
Данные берутся из `versions[version].dependencies`, а не из `latest`.
Встроенный SemVer-резолвер поддерживает точные версии, теги, `^`, `~`,
сравнения, частичные версии, `x`, `*`, дефисные диапазоны и `||`.

```powershell
.\run.bat --package is-odd --version 3.0.1 --mode direct
```
